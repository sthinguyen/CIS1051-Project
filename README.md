# CIS1051-Project
Project Video Link:
https://youtu.be/D2baoDG4kY4?si=JmWgWGOlTRwV47AI

I created a tower defense game using Python and Pygame. The game has 15 levels, a currency system, 6 unique enemy types, and 2 turret types with different upgrade stages and abilities. All artwork of the assets is done by me using Procreate and has a proper main menu screen, you win screen, and a game over screen.
